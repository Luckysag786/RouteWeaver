# 需求覆盖矩阵

| 原始需求 | Windows 实现 | Android 实现 | 验收方式 |
|---|---|---|---|
| 正向映射 | 应用/域名规则命中走原 VPN HTTP/SOCKS5 代理，未命中由网关直连 | 保存应用/域名正向规则；发现提供商并检测是否支持显式交接 | 第三方 VPN 实网：HTTP 与 SOCKS5 选中 VPN=海外，未选中直连=国内 |
| 反向隔离 | 默认转发原 VPN，命中应用/域名改为直连 | 保存反向规则；引导进入当前 VPN 的分应用设置 | 第三方 VPN 实网：命中直连=国内，未命中 VPN=海外 |
| EXE/APK 选择 | EXE 文件、任务管理器进程、桌面软件及 MSIX 应用三种来源；TCP 表反查真实来源 PID/路径 | 枚举可启动 APK，按包名多选 | Windows 目录实读与单元测试；Android JUnit 验证包名策略 |
| 网站选择 | 规范化域名、子域匹配、通配符和 IDN | 域名/子域/通配符和 IDN 规则 | Python/Java 单元测试 + HTTPS CONNECT 实网 |
| 权限设置 | 展示管理员状态、UAC 自助提权；核心 HKCU 接管不强制管理员 | 展示普通权限、VPN 槽位与 Root/提供商权限边界；选择已安装 VPN | Windows 诊断；Android 能力卡与 VpnService 枚举 |
| 测试功能 | 双出口 IP/地区、连接活动、诊断、自主刷新；选中规则可按其决策实测出口 | 默认出口与绑定物理网络出口、VPN 检测；每条规则可验证目标出口基线 | 远端 API 真实响应，保留来源和时间；Windows 规则探针与活动日志交叉验证 |
| IP 与地区准确性 | `ipwho.is` 主服务、`ifconfig.co` 备用；失败即展示错误 | `ipwho.is` 真实响应；失败即展示错误 | 中国移动 IPv6 / 美国 Oracle IPv4 实测 |
| 活动快捷规则 | 连接活动选中后显示应用、路径、网站和当前规则状态；按应用/网站一键加入或取消 | — | 纯策略单元测试与 UI 冒烟 |
| 规则维护 | 规则可修改类型、匹配值、备注和启用状态；支持查重、多选删除、双击修改和 Delete 删除 | 保存的 Android 规则可单项删除 | 规则值单元测试与 Windows 编辑/删除 UI 冒烟 |
| 开机启动与托盘 | 默认开机启动，安装器可取消；关闭默认隐藏到托盘，可在设置改为完全退出 | — | 注册表、托盘和安装卸载冒烟 |
| 不影响原 VPN | 不写 VPN 目录/进程，仅把其本地代理作为上游；停用精确恢复 | 不声明第二个 `VpnService`，不会抢占当前 VPN | 第三方 VPN 进程与本地代理入口测试前后一致 |
| 安装包 | 单文件 EXE + Inno Setup 用户级安装包 | 可侧载 debug APK | 安装/启动/卸载冒烟；Gradle 构建与单元测试 |

## 不可由普通独立应用满足的部分

- Windows 中完全忽略系统代理的 UDP、QUIC、游戏或自建协议，无法仅靠 Python 按 EXE 改写；需要签名 WFP 驱动。
- Android 中第三方 VPN 已占用唯一 `VpnService` 时，独立 APK 无权修改该服务的 allowed/disallowed app 列表。APK 因此不会显示虚假的“系统分流已应用”。
- 普通工具不能获知任意远端网站“看到的 IP”，除非该网站或 IP 回显服务返回这一信息。本项目用真实 IP 回显服务验证两条出口，并用实际网关日志验证每条目标的路由决策。
