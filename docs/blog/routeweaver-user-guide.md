## 全局网络代理带来的烦恼

很多人使用网络代理时，都遇到过这种情况：

- 不开启代理，部分软件或网页无法正常连接；
- 开启全局代理后，整台电脑的软件和网页都被统一转发；
- 原本速度正常的国内网站、网盘、视频和办公软件也开始变慢；
- 每次在“全局代理”和“关闭代理”之间来回切换，非常麻烦。

真正需要代理的可能只有一个浏览器、几个软件或少量网站，却不得不让整台电脑都受到影响。

如果你也有这个痛点，可以试试开源工具 **路由织网 RouteWeaver**。

项目中文介绍、使用教程与安装包下载：

<https://luckysag786.github.io/RouteWeaver/>

## RouteWeaver 是什么

RouteWeaver 是一个 Windows 网络代理分流工具。

它可以在已有网络代理保持开启的情况下，把代理影响范围缩小到指定应用或网站，让不需要代理的软件继续使用原来的网络连接。

简单理解就是：

```text
需要代理的软件或网站   -> 使用网络代理
其他无关软件和网站     -> 保持直接连接
```

它不会替换你原来的代理软件，也不会修改原代理客户端的内部设置，而是在电脑上增加一层可选择的分流规则。

---

## 它适合哪些用户

RouteWeaver 比较适合下面几类人：

- 必须保持网络代理开启，但不希望所有软件都走代理；
- 开启全局代理后，国内网站、网盘或视频速度明显下降；
- 只希望某个浏览器、桌面软件或指定网站使用代理；
- 希望把部分不需要代理的软件从全局代理中排除；
- 想确认某个软件实际走的是代理还是本地直连；
- 经常手动开关全局代理，觉得操作繁琐。

如果你的日常使用方式是“少数软件需要代理，大部分软件不需要”，这个工具尤其合适。

---

## 两种分流模式

### 1. 正向映射

正向映射适合只有少量软件或网站需要代理的用户。

启用后：

- 添加到规则里的软件和网站使用代理；
- 没有添加的其他软件和网站保持直连。

例如只把一个浏览器和两个网站加入规则，其他网盘、视频、聊天和办公软件就不会因为代理绕路。

### 2. 反向隔离

反向隔离适合习惯开启全局代理，只想排除部分软件的用户。

启用后：

- 默认流量继续使用代理；
- 添加到隔离规则里的软件和网站改为直连。

例如可以把国内网盘、视频软件或常用办公网站加入隔离列表，让这些项目不再经过代理。

---

## 可以按哪些方式添加软件

RouteWeaver 提供三种选择方式，不需要用户一定知道软件安装在哪个文件夹。

### 选择 EXE 文件

知道软件安装位置时，可以直接选择对应的 `.exe` 文件。

### 从运行进程中选择

软件正在运行，但找不到安装目录时，可以从当前进程列表中直接选择。

### 从已安装应用中选择

工具可以读取 Windows 已安装应用列表，通过软件名称搜索并添加。

网站规则则可以直接填写域名，例如：

```text
example.com
*.example.com
```

已有规则可以修改、启用、停用或批量删除，不需要因为填错内容重新建立整个列表。

## 如何安装和使用

### 第一步：下载安装

打开中文项目主页：

<https://luckysag786.github.io/RouteWeaver/>

普通 Windows 用户建议下载：

```text
RouteWeaver-Windows-Setup-1.3.1.exe
```

页面也提供免安装版和文件 SHA-256 校验值。

### 第二步：保持原网络代理开启

正常连接你原来使用的网络代理，不需要关闭它，也不需要修改它的内部设置。

### 第三步：启动 RouteWeaver

首次启动时，工具会尝试识别当前 Windows 系统代理，将它作为上游连接。

确认地址无误后，选择“正向映射”或“反向隔离”。

### 第四步：添加规则

根据自己的使用习惯添加：

- 指定 EXE 软件；
- 当前正在运行的进程；
- Windows 已安装应用；
- 指定网站域名。

### 第五步：启用分流

点击“启用分流”，工具就会按照规则选择代理或直连。

建议一开始只添加一个浏览器或测试网站，确认效果后再逐步增加其他规则。

---

## 怎么确认规则有没有生效

RouteWeaver 提供了几种直观的检查方式：

- 查看代理出口与直接连接出口的公网 IP 和地区；
- 对选中的单条规则执行出口测试；
- 在“连接活动”中查看软件名称、访问网站和实际分流结果；
- 从连接活动中一键添加或取消规则。

如果某条连接没有经过 RouteWeaver，它不会被虚假显示成“已经分流”。

---

## 开机启动和系统托盘

工具默认可以随 Windows 自动启动。

点击窗口右上角的关闭按钮时，默认只是隐藏到系统托盘，分流仍然保持工作，不会因为误关窗口突然中断。

如果不需要这些行为，可以在设置中关闭开机启动，或者把关闭按钮改成完全退出程序。

---

## 使用前需要知道的一点

RouteWeaver 当前主要适用于会使用 Windows 系统代理的软件和常见浏览器网页。

部分游戏、UDP/QUIC 流量，以及完全忽略系统代理的软件，可能无法通过这种方式分流。遇到某个软件没有效果时，可以先在“连接活动”中确认它的流量是否经过工具。

这项说明很重要：软件不会把没有接管的连接显示为已经生效。

---

## 总结

RouteWeaver 解决的是一个很实际的问题：

> 网络代理必须开启，但不想让所有无关软件和网页都受到影响。

通过正向映射和反向隔离，可以把代理留给真正需要的软件，让其他应用继续保持直接连接，减少不必要的网络绕行，也省去频繁切换全局代理的麻烦。
